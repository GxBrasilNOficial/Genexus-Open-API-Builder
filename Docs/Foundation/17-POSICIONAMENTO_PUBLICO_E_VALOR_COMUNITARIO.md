# 4. Problema que o Projeto Resolve

Times GeneXus frequentemente enfrentam:

- repetição manual para criar APIs CRUD
- tempo alto até primeira entrega
- diferenças técnicas entre projetos
- retrabalho em estruturas básicas
- backlog de integrações simples

## Consequência

Tempo valioso gasto em tarefas repetitivas.

[PUB-F17]

---

# 5. Proposta Pública de Valor

Transformar Transactions GeneXus em APIs REST úteis, de forma rápida, padronizada e editável.

## Em linguagem simples

Menos repetição.  
Mais entrega.  
Mais consistência.

[PUB-F17]

# 7. O Que o Projeto NÃO Promete

- substituir desenvolvedores
- gerar qualquer sistema automaticamente
- resolver regras complexas de negócio sozinho
- eliminar revisão técnica
- ser solução mágica universal

[OSS-F17]

# 8. O Que o Projeto Entrega

- aceleração de CRUD inicial
- estrutura REST previsível
- objetos editáveis

- produtividade imediata

[PUB-F17]

# 16. Uso Correto por Agentes de IA

## Pode assumir

- foco é utilidade real
- open source é valor central

- promessas futuras
- números sem evidência
- comparações absolutas
