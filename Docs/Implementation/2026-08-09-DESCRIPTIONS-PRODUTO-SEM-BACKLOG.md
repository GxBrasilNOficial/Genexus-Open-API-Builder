# Descriptions de produto sem IDs de backlog

## Estado

Validado no GeneXus 18 U15 em 2026-08-09. Código em `ApiPlanOwnedObjectDescription` e writers/remoção/Sync.

## Objetivo

Eliminar IDs de backlog (`B040`, `B050`, etc.) das `Description` dos objetos gerados, usando o padrão de produto:

`{NomeDoObjeto} - by Genexus Open API Builder`

## Formato canônico (exemplos em `Teste`)

| Objeto | Description |
|---|---|
| `procTeste_API_Update` | `procTeste_API_Update - by Genexus Open API Builder` |
| `sdtTeste_API_Response` | `sdtTeste_API_Response - by Genexus Open API Builder` |
| `apiTeste` | `apiTeste - by Genexus Open API Builder` |
| `apiTeste_Metadata` | `apiTeste_Metadata - by Genexus Open API Builder` |
| `TesteOpenApi` (criado pela extensão) | `TesteOpenApi - by Genexus Open API Builder` |
| `GxOpenAPI` (criado pela extensão) | `GxOpenAPI - by Genexus Open API Builder` |
| `GxOpenApiBuilder_Settings` | `GxOpenApiBuilder_Settings - by Genexus Open API Builder` |

Folder **reutilizado** continua sem alteração de Description.

## Legados aceitos só no reconhecimento

- Procedures/SDTs/metadata/Folder com descrições antigas compatíveis com o objeto; a combinação inteira é conferida (`B050` + `List`, `B040` + `CreateRequest`, `Transaction` + `Api`, etc.), sem aceitar prefixo divergente
- API Object: `REST API for <Transaction>, generated by Genexus Open API Builder` (com ou sem ponto)
- Preferências: `Genexus Open API Builder Wizard Preferences`
- Folder compartilhado: `Genexus Open API Builder shared SDTs folder`

A gravação nova usa apenas o formato canônico.

O reencontro não trata mais um prefixo `B0xx` como prova suficiente de posse: backlog, serviço/tipo, API e Transaction divergentes bloqueiam. A cobertura automatizada está em `Tests/OwnershipDescriptions/Test-ApiPlanOwnedObjectDescription.ps1`.
