# Release 0.1.0-alpha.1

**Data:** 2026-08-10
**Sprint:** 8 — Alpha pública
**Tag prevista:** `v0.1.0-alpha.1`

## O que entra

- Extensão GeneXus 18 com wizard funcional do MVP (validado no Upgrade 15)
- Geração de API Object, Procedures, SDTs próprios/compartilhados e metadata persistente
- Serviços `List`, `Get`, `Create` e `Update`
- Preferências do Wizard por KB
- Sincronizar com a Transaction
- Remover API gerada (conservador)
- Relatório final pós-aplicação e UX mínima de colisão
- Documentação pública: README, [INSTALL](../Public/INSTALL.md), [DEMO](../Public/DEMO.md)

## O que não entra

- Serviço `DELETE`
- Override dos templates YAML nativos do GeneXus
- Classificação canônica persistente de campos sensíveis/auditoria (`B090`/`B091`)
- Garantia de Upgrade 14 (residual)
- Pacote instalável fora do fluxo deste repositório (`Install-ExtensionForGeneXus18.bat`)

## Limitações conhecidas

- YAML OpenAPI emitido pelo GeneXus: respostas declaradas tipicamente `200`/`404`; bloco `required` de schemas pode não ser emitido pelo template nativo — ver `Docs/Implementation/2026-08-10-B088-LIMITACOES-YAML-NATIVO.md`
- Em IIS + .NET Framework, `PUT` exige ajuste do handler no nó do servidor — ver README
- Obrigatoriedade em Create/Update valida preenchimento, não presença JSON pura
- Falha IDE/SDK no meio de gravação/remoção multiobjeto pode exigir reparo manual
