This release makes the dedicated **GeneXus 18 Upgrade 13** DLL available to the community while keeping the canonical **U14+** DLL in the same Release.

## You must choose the correct DLL

Download and install only the file that matches your IDE version:

| GitHub Release asset | For | Not for |
|---|---|---|
| `GenexusOpenApiBuilder.Extension.dll` | GeneXus 18 Upgrade 14, Upgrade 15, and later U14+ releases | GeneXus 18 Upgrade 13 |
| `GenexusOpenApiBuilder.Extension-gx18u13.dll` | GeneXus 18 Upgrade 13 | GeneXus 18 U14+ |

The `-gx18u13` suffix exists to distinguish the public download. Do not rename a DLL to make it look like another line, and do not install both DLLs in the same IDE.

## What is included

- Public distribution of `GenexusOpenApiBuilder.Extension-gx18u13.dll` for GeneXus 18 U13.
- `NoAccept` rule fix: read-only attributes are excluded from `Create` and `Update` requests while remaining available in `Response`, `ListResponse`, and filters.
- Public documentation explaining which DLL to select for each Upgrade.
- The canonical `GenexusOpenApiBuilder.Extension.dll` asset for U14+.

## Validation

- U13: the satellite build that produces the asset was loaded, and main and context menus, Wizard, API removal and recreation, and `Build All` completed; focused Create/Update builds finished without `spc0018` after the `NoAccept` fix.
- U15: the `NoAccept` contract was revalidated after API removal and recreation; `Build All` completed without `spc0018`.
- HTTP: `apiNotaFiscal` was revalidated on .NET Framework/SQL Server and .NET/PostgreSQL with OAuth, List, Get, Create, Update, `Location`, filtering, 404, and 400 cases.
- Assets: manifest, entry class, `PackageCompatibility`, informational version, file name, and SHA-256 were validated by the Release checker.

## Installation

Follow the [public installation guide](../Public/INSTALL.md). In brief:

1. choose the DLL using the table above;
2. with the GeneXus IDE open, use **Extensions Manager → Add > Local**;
3. close the IDE completely;
4. run `genexus /install` in the corresponding installation;
5. reopen the IDE and verify the Genexus Open API Builder menus.

The GitHub Packages `.nupkg` is not the IDE installer. For public installation, use the Release DLL asset.

## Known limitations

- The `DELETE` service is not part of the MVP.
- GeneXus native OpenAPI YAML retains the limitations documented in [B088](../Implementation/2026-08-10-B088-LIMITACOES-YAML-NATIVO.md).
- On IIS + .NET Framework, the `PUT` verb requires the handler adjustment described in the [README](../../README.md#requisito-de-ambiente-put-delete-e-patch-em-iis).
- Installation without elevation and updates performed only through Add > Local over an already installed DLL remain unproven.
- This is still an Alpha, not a Beta; Sprint 9 external feedback and known limitations remain explicit.
