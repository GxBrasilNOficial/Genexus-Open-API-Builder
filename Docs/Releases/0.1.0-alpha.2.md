**Data:** 2026-08-13

**Frente:** distribuição da linha GeneXus 18 U13

**Tag:** `v0.1.0-alpha.2`

Esta versão libera para a comunidade a DLL específica do **GeneXus 18 Upgrade 13**, mantendo no mesmo Release a DLL canônica para **U14+**.

## Escolha obrigatória da DLL

Baixe e instale somente o arquivo correspondente à versão da sua IDE:

| Asset no GitHub Release | Serve para | Não serve para |
|---|---|---|
| `GenexusOpenApiBuilder.Extension.dll` | GeneXus 18 Upgrade 14, Upgrade 15 e posteriores U14+ | GeneXus 18 Upgrade 13 |
| `GenexusOpenApiBuilder.Extension-gx18u13.dll` | GeneXus 18 Upgrade 13 | GeneXus 18 U14+ |

O sufixo `-gx18u13` existe para distinguir o download público. Não renomeie uma DLL para fazê-la passar por outra linha e não instale as duas na mesma IDE.

## O que entra

- Distribuição pública do asset `GenexusOpenApiBuilder.Extension-gx18u13.dll` para o GeneXus 18 U13.
- Correção das regras `NoAccept`: atributos somente leitura não são incluídos nos requests `Create` e `Update`, mas continuam disponíveis em `Response`, `ListResponse` e filtros.
- Documentação pública com a seleção da DLL por Upgrade.
- Asset canônico `GenexusOpenApiBuilder.Extension.dll` para U14+.

## Validações

- U13: a build satélite que dá origem ao asset foi carregada, os menus principal e de contexto, Wizard, remoção e recriação da API e `Build All` foram concluídos; o build focado de Create/Update terminou sem `spc0018` após a correção de `NoAccept`.
- U15: contrato `NoAccept` revalidado após remoção e recriação da API; `Build All` concluído sem `spc0018`.
- HTTP: `apiNotaFiscal` revalidada em .NET Framework/SQL Server e .NET/PostgreSQL com OAuth, List, Get, Create, Update, `Location`, filtro, 404 e 400.
- Assets: manifesto, classe de entrada, `PackageCompatibility`, versão informacional, nome do arquivo e SHA-256 validados pelo checker de Release.

## Instalação

Siga o [guia público de instalação](../Public/INSTALL.md). Em resumo:

1. escolha a DLL pela tabela acima;
2. na IDE GeneXus aberta, use **Extensions Manager → Add > Local**;
3. feche completamente a IDE;
4. execute `genexus /install` na instalação correspondente;
5. reabra a IDE e confira os menus do Genexus Open API Builder.

O `.nupkg` do GitHub Packages não é o instalador da IDE. Para a instalação pública, use o asset DLL do Release.

## Limitações conhecidas

- Serviço `DELETE` não faz parte do MVP.
- O YAML OpenAPI nativo do GeneXus mantém as limitações documentadas em [B088](../Implementation/2026-08-10-B088-LIMITACOES-YAML-NATIVO.md).
- Em IIS + .NET Framework, o verbo `PUT` exige o ajuste do handler descrito no [README](../../README.md#requisito-de-ambiente-put-delete-e-patch-em-iis).
- Instalação sem elevação alguma e atualização somente por Add > Local sobre DLL já instalada continuam sem comprovação.
- A Alpha ainda não é a Beta; a Sprint 9 de feedback externo e as limitações conhecidas permanecem explícitas.
