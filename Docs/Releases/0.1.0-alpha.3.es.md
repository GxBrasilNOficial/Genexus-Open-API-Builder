# Release 0.1.0-alpha.3

**Fecha:** 2026-08-18

**Frente:** localización trilingüe, restauración y robustez del Wizard, y estandarización de contratos

**Tag:** `v0.1.0-alpha.3`
**Release:** [Alpha en GitHub](https://github.com/GxBrasilNOficial/Genexus-Open-API-Builder/releases/tag/v0.1.0-alpha.3)

**Idiomas:** [Português do Brasil](0.1.0-alpha.3.md) · [Español](0.1.0-alpha.3.es.md) · [English](0.1.0-alpha.3.en.md)

Esta versión entrega la localización trilingüe completa de la extensión (Portugués, Español e Inglés), restauración y robustez en el ciclo de vida del Wizard y estandarización del contrato de error.

## Elija obligatoriamente la DLL correcta

Descargue e instale solamente el archivo correspondiente a la versión de su IDE:

| Asset en GitHub Release | Sirve para | No sirve para |
|---|---|---|
| `GenexusOpenApiBuilder.Extension.dll` | GeneXus 18 Upgrade 14, Upgrade 15 y posteriores U14+ | GeneXus 18 Upgrade 13 |
| `GenexusOpenApiBuilder.Extension-gx18u13.dll` | GeneXus 18 Upgrade 13 | GeneXus 18 U14+ |

El sufijo `-gx18u13` existe para distinguir la descarga pública. No cambie el nombre de una DLL para hacerla pasar por otra línea y no instale las dos en el mismo IDE.

## Qué incluye

- **Localización trilingüe completa:** detección automática por el idioma de la KB con catálogo centralizado (`pt-BR`, `es`, `en`), traducción de los comandos del manifiesto, diálogos del Wizard, Sincronización, Preferencias, Reporte Final y mensajes en la ventana Output.
- **Restauración de selecciones y filtros en el Wizard:** al reabrir el Wizard en una API existente, las selecciones de servicios, campos y filtros configurados se restauran a partir de la metadata, SDTs y API Object.
- **Robustez en el reencuentro del Wizard:** soporte para nombres personalizados de API vía metadata, soporte para planes parciales solo `List`/`Get`, parse tolerante de `Service Source` sin duplicidades y lectura de SDTs propios sin metadata.
- **Estandarización de contrato HTTP:** contrato de error de `List` alineado con `Create` y `Update` con `ErrorResponse`, `RestStatusCode=400` y eliminación de `msg()`.
- **Integridad de metadata (B060):** corrección del parser de fechas para evitar falsos positivos con ceros fraccionarios en el hash SHA-256.
- **Documentación pública trilingüe:** READMEs públicos con paridad de contenido en portugués, español e inglés.

## Instalación

Siga la [guía pública de instalación](../Public/INSTALL.md). En resumen:

1. elija la DLL según la tabla anterior;
2. con la IDE GeneXus abierta, use **Extensions Manager → Add > Local**;
3. cierre completamente la IDE;
4. ejecute `genexus /install` en la instalación correspondiente;
5. vuelva a abrir la IDE y confirme los menús de Genexus Open API Builder.

El `.nupkg` de GitHub Packages no es el instalador de la IDE. Para la instalación pública, use el asset DLL del Release.

## Limitaciones conocidas

- El servicio `DELETE` no forma parte del MVP.
- El YAML OpenAPI nativo de GeneXus mantiene las limitaciones documentadas en [B088](../Implementation/2026-08-10-B088-LIMITACOES-YAML-NATIVO.md).
- En IIS + .NET Framework, el verbo `PUT` requiere el ajuste del handler descrito en el [README](../../README.md#requisito-de-ambiente-put-delete-e-patch-em-iis).
- La instalación sin elevación y la actualización solamente por Add > Local sobre una DLL ya instalada continúan sin comprobación.
- Esta versión sigue siendo Alpha, no Beta; permanecen explícitos el feedback externo de la Sprint 9 y las limitaciones conocidas.
