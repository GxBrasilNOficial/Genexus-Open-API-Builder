# Release 0.1.0-alpha.3

**Data:** 2026-08-18

**Frente:** localização trilíngue, restauração e robustez do Wizard, e padronização de contratos

**Tag:** `v0.1.0-alpha.3`
**Release:** [Alpha no GitHub](https://github.com/GxBrasilNOficial/Genexus-Open-API-Builder/releases/tag/v0.1.0-alpha.3)

**Idiomas:** [Português do Brasil](0.1.0-alpha.3.md) · [Español](0.1.0-alpha.3.es.md) · [English](0.1.0-alpha.3.en.md)

Esta versão entrega a localização trilíngue completa da extensão (Português, Espanhol e Inglês), restauração e robustez no ciclo de vida do Wizard e padronização do contrato de erro.

## Escolha obrigatória da DLL

Baixe e instale somente o arquivo correspondente à versão da sua IDE:

| Asset no GitHub Release | Serve para | Não serve para |
|---|---|---|
| `GenexusOpenApiBuilder.Extension.dll` | GeneXus 18 Upgrade 14, Upgrade 15 e posteriores U14+ | GeneXus 18 Upgrade 13 |
| `GenexusOpenApiBuilder.Extension-gx18u13.dll` | GeneXus 18 Upgrade 13 | GeneXus 18 U14+ |

O sufixo `-gx18u13` existe para distinguir o download público. Não renomeie uma DLL para fazê-la passar por outra linha e não instale as duas na mesma IDE.

## O que entra

- **Localização trilíngue completa:** detecção automática pelo idioma da KB com catálogo centralizado (`pt-BR`, `es`, `en`), tradução dos comandos do manifesto, diálogos do Wizard, Sincronização, Preferências, Relatório Final e mensagens na janela Output.
- **Restauração de seleções e filtros no Wizard:** ao reabrir o Wizard em API existente, seleções de serviços, campos e filtros configurados são restaurados a partir da metadata, SDTs e API Object.
- **Robustez no reencontro do Wizard:** suporte a nomes customizados de API via metadata, suporte a planos parciais somente `List`/`Get`, parse tolerante de `Service Source` sem duplicidades e leitura de SDTs próprios sem metadata.
- **Padronização de contrato HTTP:** contrato de erro de `List` alinhado a `Create` e `Update` com `ErrorResponse`, `RestStatusCode=400` e eliminação de `msg()`.
- **Integridade da metadata (B060):** correção do parser de data para evitar falsos positivos com zeros fracionários no hash SHA-256.
- **Documentação pública trilíngue:** READMEs públicos com paridade de conteúdo em português, espanhol e inglês.

## Instalação

Siga o [guia público de instalação](../Public/INSTALL.md). Em resumo:

1. escolha a DLL pela tabela acima;
2. na IDE GeneXus aberta, use **Extensions Manager → Add > Local**;
3. feche completamente a IDE;
4. execute `genexus /install` na instalação correspondente;
5. reabra a IDE e confira os menus do Genexus Open API Builder.

O `.nupkg` do GitHub Packages não é o instalador da IDE. Para a instalação pública, use o asset DLL do Release.

## Limitações conhecidas

- Serviço `DELETE` não faz parte do MVP.
- O YAML OpenAPI nativo do GeneXus mantém as limitações documentadas em [B088](../Implementation/2026-08-10-B088-LIMITACOES-YAML-NATIVO.md).
- Em IIS + .NET Framework, o verbo `PUT` exige o ajuste do handler descrito no [README](../../README.md#requisito-de-ambiente-put-delete-e-patch-em-iis).
- Instalação sem elevação alguma e atualização somente por Add > Local sobre DLL já instalada continuam sem comprovação.
- A Alpha ainda não é a Beta; a Sprint 9 de feedback externo e as limitações conhecidas permanecem explícitas.
