# Release 0.1.0-alpha.6

**Fecha:** 2026-08-31

**Frente:** Sprint 9 — servicio `Delete` opt-in (`B100`)

**Tag:** `v0.1.0-alpha.6` (publicación bajo autorización humana)
**Release:** [Alpha en GitHub](https://github.com/GxBrasilNOficial/Genexus-Open-API-Builder/releases/tag/v0.1.0-alpha.6) (después de la publicación)

**Idiomas:** [Português do Brasil](0.1.0-alpha.6.md) · [Español](0.1.0-alpha.6.es.md) · [English](0.1.0-alpha.6.en.md)

Esta versión agrega el servicio REST `Delete` como opción explícita en el Wizard, desactivado por defecto.

## Cambio de comportamiento

No es un ítem de la lista de mejoras: quien ya genera o consume APIs de esta extensión necesita saber esto.

- El `Delete` **no entra solo** en una API ya generada. Reabra el Wizard, marque la casilla y complete el Apply con Completar REST via Business Component.
- Marcar `Delete` exige Completar REST via Business Component en el mismo Apply. Sin esa etapa no hay `proc*_API_Delete` ni ruta en el API Object.
- Las preferencias de la KB rechazan grabar solo `Delete` sin `Get`, `Create` y `Update`.
- El `Delete` tiene `SecurityLevel` propio (combo). En el reencuentro, el radio del Wizard vale para `List`/`Get`/`Create`/`Update`; Sync conserva el nivel del `Delete`.
- Borrar el encabezado borra las líneas hijas en la misma transacción Business Component. Un `404` en id inexistente **no** es idempotente (`200`).
- Ante rechazo por integridad referencial, el `Delete` responde **HTTP 422** con el mismo SDT de error de `Create`/`Update` (`validation_error`, `Message`, `Messages[]` cuando el repaso de mensajes esté activo).

El soporte a subniveles de `0.1.0-alpha.5` y el contrato HTTP 422 de `0.1.0-alpha.4` se mantienen.

## Elija obligatoriamente la DLL correcta

Descargue e instale solamente el archivo correspondiente a la versión de su IDE:

| Asset en GitHub Release | Sirve para | No sirve para |
|---|---|---|
| `GenexusOpenApiBuilder.Extension.dll` | GeneXus 18 Upgrade 14, Upgrade 15 y posteriores U14+ | GeneXus 18 Upgrade 13 |
| `GenexusOpenApiBuilder.Extension-gx18u13.dll` | GeneXus 18 Upgrade 13 | GeneXus 18 U14+ |

El sufijo `-gx18u13` existe para distinguir la descarga pública. No cambie el nombre de una DLL para hacerla pasar por otra línea y no instale las dos en el mismo IDE.

## Qué incluye

- Servicio REST `Delete` opt-in: Procedure `proc*_API_Delete`, método `DELETE` en el path de la clave del `Get`, estados `200` / `404` / `422` via Business Component.
- Confirmación al marcar la casilla; `SecurityLevel` propio; dependencia de Completar REST via Business Component.
- Reencuentro y Sync alineados al nivel propio del `Delete`.
- Documentación pública (README ×3, `DEMO`, contratos Foundation) alineada al contrato opt-in.

## Validaciones

- HTTP en `apiNotaFiscal`: `401` sin token, `404` en inexistente, `200` con exclusión en los environments `.NET`/PostgreSQL y `.NET Framework`/SQL Server; `422` de integridad en Framework.
- Nivel propio en IIS: `Delete` con `SecurityHigh` y el resto con `SecurityLow`; usuario sin permiso de Delete recibe `403` `code` 139; usuario con permiso crea/consulta/excluye con `201`/`200`/`404` coherentes.
- Smoke U15 de reencuentro, Sync, dependencia BC, Output `B050-B053/B100`, vista previa y preferencias.
- Líneas U14+ (canónica) y U13 (satélite) compiladas en Release para este corte.

## Instalación

Siga la [guía pública de instalación](../Public/INSTALL.md). En resumen:

1. elija la DLL según la tabla anterior;
2. con la IDE GeneXus abierta, use **Extensions Manager → Add > Local**;
3. cierre completamente la IDE;
4. ejecute `genexus /install` en la instalación correspondiente;
5. vuelva a abrir la IDE y confirme los menús de Genexus Open API Builder.

El `.nupkg` de GitHub Packages no es el instalador de la IDE. Para la instalación pública, use el asset DLL del Release.

## Limitaciones conocidas

- `Delete` sigue siendo opt-in y desactivado por defecto; una API anterior solo gana el endpoint al reabrir el Wizard con la casilla marcada.
- Las preferencias de la KB todavía pueden volver a marcar casillas de generación en el reencuentro (`B108`, pendiente; fuera de este corte).
- Las limitaciones de subniveles de `0.1.0-alpha.5` permanecen (sin endpoints propios de subnivel; contadores solo en hijos directos; profundidad mayor que 4 avisa).
- El YAML OpenAPI nativo de GeneXus mantiene las limitaciones documentadas en [B088](../Implementation/2026-08-10-B088-LIMITACOES-YAML-NATIVO.md).
- En IIS + .NET Framework, los verbos `PUT` y `DELETE` requieren el ajuste del handler descrito en el [README](../../README.md#requisito-de-ambiente-put-delete-e-patch-em-iis).
- La instalación sin elevación y la actualización solamente por Add > Local sobre una DLL ya instalada continúan sin comprobación.
- Esta versión sigue siendo Alpha, no Beta.
