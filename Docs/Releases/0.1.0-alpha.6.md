# Release 0.1.0-alpha.6

**Data:** 2026-08-31

**Frente:** Sprint 9 — serviço `Delete` opt-in (`B100`)

**Tag:** `v0.1.0-alpha.6` (publicação sob autorização humana)
**Release:** [Alpha no GitHub](https://github.com/GxBrasilNOficial/Genexus-Open-API-Builder/releases/tag/v0.1.0-alpha.6) (após a publicação)

**Idiomas:** [Português do Brasil](0.1.0-alpha.6.md) · [Español](0.1.0-alpha.6.es.md) · [English](0.1.0-alpha.6.en.md)

Esta versão acrescenta o serviço REST `Delete` como opção explícita no Wizard, desligado por padrão.

## Mudança de comportamento

Não é um item da lista de melhorias: quem já gera ou consome APIs desta extensão precisa saber disto.

- O `Delete` **não entra sozinho** em API já gerada. Reabra o Wizard, marque o checkbox e conclua o Apply com a etapa Completar REST via Business Component.
- Marcar `Delete` exige Completar REST via Business Component no mesmo Apply. Sem essa etapa não há `proc*_API_Delete` nem rota no API Object.
- Preferências da KB recusam gravar só `Delete` sem `Get`, `Create` e `Update`.
- O `Delete` tem `SecurityLevel` próprio (combo). No reencontro, o rádio do Wizard vale para `List`/`Get`/`Create`/`Update`; o Sync preserva o nível do `Delete`.
- Apagar o cabeçalho apaga as linhas filhas na mesma transação Business Component. `404` em id inexistente **não** é idempotente (`200`).
- Em recusa por integridade referencial, o `Delete` responde **HTTP 422** com o mesmo SDT de erro de `Create`/`Update` (`validation_error`, `Message`, `Messages[]` quando o repasse estiver ligado).

O suporte a subníveis de `0.1.0-alpha.5` e o contrato HTTP 422 de `0.1.0-alpha.4` permanecem.

## Escolha obrigatória da DLL

Baixe e instale somente o arquivo correspondente à versão da sua IDE:

| Asset no GitHub Release | Serve para | Não serve para |
|---|---|---|
| `GenexusOpenApiBuilder.Extension.dll` | GeneXus 18 Upgrade 14, Upgrade 15 e posteriores U14+ | GeneXus 18 Upgrade 13 |
| `GenexusOpenApiBuilder.Extension-gx18u13.dll` | GeneXus 18 Upgrade 13 | GeneXus 18 U14+ |

O sufixo `-gx18u13` existe para distinguir o download público. Não renomeie uma DLL para fazê-la passar por outra linha e não instale as duas na mesma IDE.

## O que entra

- Serviço REST `Delete` opt-in: Procedure `proc*_API_Delete`, método `DELETE` no path da chave do `Get`, status `200` / `404` / `422` via Business Component.
- Confirmação ao marcar o checkbox; `SecurityLevel` próprio; dependência da etapa Completar REST via Business Component.
- Reencontro e Sync alinhados ao nível próprio do `Delete`.
- Documentação pública (README ×3, `DEMO`, contratos Foundation) alinhada ao contrato opt-in.

## Validações

- HTTP na `apiNotaFiscal`: `401` sem token, `404` em inexistente, `200` com exclusão nos environments `.NET`/PostgreSQL e `.NET Framework`/SQL Server; `422` de integridade no Framework.
- Nível próprio no IIS: `Delete` com `SecurityHigh` e demais com `SecurityLow`; usuário sem permissão de Delete recebe `403` `code` 139; usuário com permissão cria/consulta/exclui com `201`/`200`/`404` coerentes.
- Smoke U15 de reencontro, Sync, dependência BC, Output `B050-B053/B100`, prévia e preferências.
- Linhas U14+ (canônica) e U13 (satélite) compiladas em Release para este corte.

## Instalação

Siga o [guia público de instalação](../Public/INSTALL.md). Em resumo:

1. escolha a DLL pela tabela acima;
2. na IDE GeneXus aberta, use **Extensions Manager → Add > Local**;
3. feche completamente a IDE;
4. execute `genexus /install` na instalação correspondente;
5. reabra a IDE e confira os menus do Genexus Open API Builder.

O `.nupkg` do GitHub Packages não é o instalador da IDE. Para a instalação pública, use o asset DLL do Release.

## Limitações conhecidas

- `Delete` continua opt-in e desligado por padrão; API anterior só ganha o endpoint ao reabrir o Wizard com o checkbox marcado.
- Preferências da KB ainda podem religar checkboxes de geração no reencontro (`B108`, pendente; fora deste corte).
- Limitações de subníveis de `0.1.0-alpha.5` permanecem (sem endpoints próprios de subnível; contadores só nos filhos diretos; profundidade acima de 4 avisa).
- O YAML OpenAPI nativo do GeneXus mantém as limitações documentadas em [B088](../Implementation/2026-08-10-B088-LIMITACOES-YAML-NATIVO.md).
- Em IIS + .NET Framework, os verbos `PUT` e `DELETE` exigem o ajuste do handler descrito no [README](../../README.md#requisito-de-ambiente-put-delete-e-patch-em-iis).
- Instalação sem elevação alguma e atualização somente por Add > Local sobre DLL já instalada continuam sem comprovação.
- A Alpha ainda não é a Beta.
