# Português (Brasil)

Esta versão introduz feedback visual de progresso em tempo real e cancelamento cooperativo (`B082`), evitando que a IDE pareça travada durante operações longas no Wizard, Apply, Sincronização e Remoção. As operações passam a utilizar indexação em memória de objetos da KB, reduzindo significativamente o tempo de processamento em estruturas multiníveis ou KBs volumosas.

## Escolha a DLL correta

| Arquivo | Serve para |
| --- | --- |
| `GenexusOpenApiBuilder.Extension.dll` | GeneXus 18 Upgrade 14, U15 e posteriores U14+. Não usar no U13. |
| `GenexusOpenApiBuilder.Extension-gx18u13.dll` | GeneXus 18 Upgrade 13. Não usar no U14 ou posterior. |

O sufixo `-gx18u13` diferencia apenas o download. Não renomeie a DLL e não instale as duas na mesma IDE.

## Instalação

Na IDE GeneXus, abra **Extensions > Manage Extensions**, use **Add > Local** e selecione a DLL correspondente à sua versão. Feche completamente a IDE e execute `genexus /install` conforme a documentação de instalação.

Notas detalhadas: [Português-BR](https://github.com/GxBrasilNOficial/Genexus-Open-API-Builder/blob/v0.1.0-alpha.7/Docs/Releases/0.1.0-alpha.7.md).

# Español

Esta versión introduce retroalimentación visual de progreso en tiempo real y cancelación cooperativa (`B082`), evitando que la IDE parezca congelada durante operaciones largas en el Wizard, Apply, Sincronización y Eliminación. Las operaciones ahora utilizan indexación en memoria de objetos de la KB, reduciendo significativamente el tiempo de procesamiento en estructuras multinivel o KBs grandes.

## Elija la DLL correcta

| Archivo | Sirve para |

El sufijo `-gx18u13` solo diferencia la descarga. No cambie el nombre de la DLL ni instale las dos en la misma IDE.

En la IDE de GeneXus, abra **Extensions > Manage Extensions**, use **Add > Local** y seleccione la DLL correspondiente a su versión. Cierre completamente la IDE y ejecute `genexus /install` según la documentación de instalación.

Notas detalladas: [Español](https://github.com/GxBrasilNOficial/Genexus-Open-API-Builder/blob/v0.1.0-alpha.7/Docs/Releases/0.1.0-alpha.7.es.md).

# English

This release introduces real-time visual progress feedback and cooperative cancellation (`B082`), preventing the IDE from appearing frozen during long operations in Wizard, Apply, Sync, and Removal. Operations now leverage in-memory KB object indexing, significantly reducing processing time on multilevel structures and large KBs.

## Choose the correct DLL

| File | Intended for |
| --- | --- |
| `GenexusOpenApiBuilder.Extension.dll` | GeneXus 18 Upgrade 14, U15, and later U14+ releases. Do not use with U13. |
| `GenexusOpenApiBuilder.Extension-gx18u13.dll` | GeneXus 18 Upgrade 13. Do not use with U14 or later. |

The `-gx18u13` suffix only distinguishes the download. Do not rename the DLL or install both DLLs in the same IDE.

## Installation

In the GeneXus IDE, open **Extensions > Manage Extensions**, use **Add > Local**, and select the DLL that matches your version. Close the IDE completely and run `genexus /install` according to the installation documentation.

Detailed notes: [English](https://github.com/GxBrasilNOficial/Genexus-Open-API-Builder/blob/v0.1.0-alpha.7/Docs/Releases/0.1.0-alpha.7.en.md).
