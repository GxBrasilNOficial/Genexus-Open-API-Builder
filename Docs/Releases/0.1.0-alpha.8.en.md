# Release 0.1.0-alpha.8

**Date:** 2026-09-17

**Workstream:** Sprint `S-B111` F3 — durable operation journal, recovery, and `B082` residual

**Tag:** `v0.1.0-alpha.8`
**Release:** [Alpha on GitHub](https://github.com/GxBrasilNOficial/Genexus-Open-API-Builder/releases/tag/v0.1.0-alpha.8)

**Languages:** [Português do Brasil](0.1.0-alpha.8.md) · [Español](0.1.0-alpha.8.es.md) · [English](0.1.0-alpha.8.en.md)

This release records in the Knowledge Base what the extension intends to do **before** mutating objects, blocks Apply/Sync/Remove when an operation is left interrupted, and ships **Recover interrupted operation**. It also closes the `B082` performance/safety residual.

## What changes for the user

- **Journal in the KB:** Apply, Sync, and Remove write the `GxOpenApiBuilder_OperationJournal` File (Root Module) before saving or deleting business objects.
- **Safe block:** a non-terminal envelope prevents the next operation; the reason appears in the report.
- **Recover interrupted operation:** on the main menu and Transaction context menu — resume removal, close a finished record, or **discard the record** (without deleting objects) when Apply/Sync stopped mid-way.
- **Honest Abort:** the progress UI is modeless; Abort finishes the in-flight object and may leave the KB partial — recovery is the exit path, not “safe before any write”.
- **Removal:** single multi-pass queue; a second removal of the same API no longer looks like a silent success when targets are already gone.
- **B082 residual:** coherent index on Remove, single-operation guard, and Preview/Folder hardening.

**Declared limitation:** automatic continuation of an interrupted Apply or Sync **does not** exist in this Alpha.

Visual progress (`0.1.0-alpha.7`), opt-in `Delete` (`0.1.0-alpha.6`), sublevels (`0.1.0-alpha.5`), and the HTTP 422 contract (`0.1.0-alpha.4`) remain.

## You must choose the correct DLL

Download and install only the file that matches your IDE version:

| GitHub Release asset | For | Not for |
|---|---|---|
| `GenexusOpenApiBuilder.Extension.dll` | GeneXus 18 Upgrade 14, Upgrade 15, and later (**U14+**) | GeneXus 18 **U13−** (Upgrade 13 and earlier) |
| `GenexusOpenApiBuilder.Extension-gx18u13.dll` | GeneXus 18 Upgrade 13 and earlier (**U13−**) | GeneXus 18 **U14+** |

The `-gx18u13` suffix exists to distinguish the public download. Do not rename a DLL to make it look like another line, and do not install both DLLs in the same IDE. The **U13−** line is formally validated on Upgrade 13; earlier upgrades may work, without a complete test matrix in this Alpha.

## What is included

- Journal schema V1, confirmed checkpoints, classified gate, and per-target inventory/receipts.
- `Recover interrupted operation` command and `ShowRecoveryOptionProactively` preference (on by default).
- Business metadata `GOAB_API_METADATA_B060_V3` with `ownership.applicationId` (V1/V2-tolerant reads).
- Orphan metadata recovery when opening the Wizard; Diagnostics and recovery section in Preferences.
- Journal/recovery localization fixes and translation-catalog ordering by length.
- `B082` residual stages 1B/2/3.

## Installation

Follow the [public installation guide](../Public/INSTALL.md). In short:

1. choose the DLL from the table above;
2. with the GeneXus IDE open, use **Extensions Manager → Add > Local**;
3. close the IDE completely;
4. run `genexus /install` in the matching installation;
5. reopen the IDE and check the menus — including **Recover interrupted operation**.

The GitHub Packages `.nupkg` is not the IDE installer. For public install, use the Release DLL asset.

## Known limitations

- Continuing an interrupted Apply/Sync is out of scope; use Recover to discard the record, then Wizard or Remove.
- KB preferences may still re-check generation checkboxes on reencounter (`B108`, parked; outside this cut).
- Sublevel limitations from `0.1.0-alpha.5` remain.
- Native GeneXus OpenAPI YAML keeps the limitations documented in [B088](../Implementation/2026-08-10-B088-LIMITACOES-YAML-NATIVO.md).
- On IIS + .NET Framework, `PUT` and `DELETE` require the handler adjustment described in the [README](../../README.md#requisito-de-ambiente-put-delete-e-patch-em-iis).
- Alpha is still not Beta.
