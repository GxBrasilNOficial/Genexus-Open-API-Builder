# Release 0.1.0-alpha.8

**Fecha:** 2026-09-17

**Frente:** Sprint `S-B111` F3 — diario durable de operación, recuperación y residual `B082`

**Tag:** `v0.1.0-alpha.8`
**Release:** [Alpha en GitHub](https://github.com/GxBrasilNOficial/Genexus-Open-API-Builder/releases/tag/v0.1.0-alpha.8)

**Idiomas:** [Português do Brasil](0.1.0-alpha.8.md) · [Español](0.1.0-alpha.8.es.md) · [English](0.1.0-alpha.8.en.md)

Esta versión registra en la Knowledge Base lo que la extensión pretende hacer **antes** de mutar objetos, bloquea Apply/Sync/Remover cuando una operación queda interrumpida, y entrega el comando **Recuperar operación interrumpida**. También cierra el residual de rendimiento/seguridad de `B082`.

## Qué cambia para el usuario

- **Diario en la KB:** Apply, Sync y Remover graban el File `GxOpenApiBuilder_OperationJournal` (Root Module) antes de grabar o borrar objetos de negocio.
- **Bloqueo seguro:** un envelope no terminal impide la operación siguiente; el motivo aparece en el informe.
- **Recuperar operación interrumpida:** en el menú principal y en el contexto de la Transaction — reanudar eliminación, cerrar un registro concluido o **cerrar el registro** (sin borrar objetos) cuando Apply/Sync se detuvieron a medias.
- **Abortar honesto:** el cuadro de progreso es modeless; Abortar termina el objeto en curso y puede dejar la KB parcial — la salida es la recuperación, no «seguro antes de cualquier grabación».
- **Eliminación:** cola única por pasadas; una segunda eliminación de la misma API deja de parecer un éxito silencioso cuando los destinos ya no están.
- **Residual B082:** índice coherente en Remover, guarda de operación única y endurecimientos de Preview/Folder.

**Limitación declarada:** la continuación automática de Apply o Sync interrumpido **no** existe en esta Alpha.

El progreso visual (`0.1.0-alpha.7`), el `Delete` opt-in (`0.1.0-alpha.6`), los subniveles (`0.1.0-alpha.5`) y el contrato HTTP 422 (`0.1.0-alpha.4`) se mantienen.

## Elija obligatoriamente la DLL correcta

Descargue e instale solamente el archivo correspondiente a la versión de su IDE:

| Asset en GitHub Release | Sirve para | No sirve para |
|---|---|---|
| `GenexusOpenApiBuilder.Extension.dll` | GeneXus 18 Upgrade 14, Upgrade 15 y posteriores U14+ | GeneXus 18 Upgrade 13 |
| `GenexusOpenApiBuilder.Extension-gx18u13.dll` | GeneXus 18 Upgrade 13 | GeneXus 18 U14+ |

El sufijo `-gx18u13` existe para distinguir la descarga pública. No cambie el nombre de una DLL para hacerla pasar por otra línea y no instale las dos en el mismo IDE.

## Qué incluye

- Schema V1 del diario, checkpoints confirmados, gate clasificado e inventario/recibos por destino.
- Comando `Recuperar operación interrumpida` y preferencia `ShowRecoveryOptionProactively` (activada por defecto).
- Metadata de negocio `GOAB_API_METADATA_B060_V3` con `ownership.applicationId` (lectura tolerante a V1/V2).
- Recuperación de metadata huérfana al abrir el Wizard; cuadro Diagnóstico y recuperación en Preferencias.
- Correcciones de localización del diario/recuperación y del catálogo de traducción.
- Residual `B082` Etapas 1B/2/3.

## Instalación

Siga la [guía pública de instalación](../Public/INSTALL.md). En resumen:

1. elija la DLL según la tabla;
2. con la IDE GeneXus abierta, use **Extensions Manager → Add > Local**;
3. cierre completamente la IDE;
4. ejecute `genexus /install` en la instalación correspondiente;
5. reabra la IDE y verifique los menús — incluido **Recuperar operación interrumpida**.

El `.nupkg` de GitHub Packages no es el instalador de la IDE. Para la instalación pública, use el asset DLL del Release.

## Limitaciones conocidas

- Continuación de Apply/Sync interrumpido fuera de alcance; use Recuperar para cerrar el registro y después Wizard o Remover.
- Las preferencias de la KB aún pueden volver a marcar checkboxes de generación en el reencuentro (`B108`, estacionado; fuera de este corte).
- Las limitaciones de subniveles de `0.1.0-alpha.5` permanecen.
- El YAML OpenAPI nativo de GeneXus mantiene las limitaciones documentadas en [B088](../Implementation/2026-08-10-B088-LIMITACOES-YAML-NATIVO.md).
- En IIS + .NET Framework, los verbos `PUT` y `DELETE` exigen el ajuste del handler descrito en el [README](../../README.md#requisito-de-ambiente-put-delete-e-patch-em-iis).
- La Alpha aún no es la Beta.
