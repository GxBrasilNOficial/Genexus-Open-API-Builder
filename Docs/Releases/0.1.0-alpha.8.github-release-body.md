# Português (Brasil)

Esta versão introduz o diário durável de operação (`GxOpenApiBuilder_OperationJournal`) e o comando **Recuperar operação interrompida**: Apply, Sync e Remover registram a intenção antes de mutar a KB; um envelope interrompido bloqueia a operação seguinte até a recuperação. Fecha também o residual `B082` (índice no Remover e endurecimentos de segurança). Continuação automática de Apply/Sync interrompido **não** existe nesta Alpha.

## Escolha a DLL correta

| Arquivo | Serve para |
| --- | --- |
| `GenexusOpenApiBuilder.Extension.dll` | GeneXus 18 Upgrade 14, U15 e posteriores (**U14+**). Não usar em **U13−**. |
| `GenexusOpenApiBuilder.Extension-gx18u13.dll` | GeneXus 18 Upgrade 13 e anteriores (**U13−**). Não usar em **U14+**. Validação formal no U13. |

O sufixo `-gx18u13` diferencia apenas o download. Não renomeie a DLL e não instale as duas na mesma IDE.

## Instalação

Na IDE GeneXus, abra **Extensions > Manage Extensions**, use **Add > Local** e selecione a DLL correspondente à sua versão. Feche completamente a IDE e execute `genexus /install` conforme a documentação de instalação. Confira o menu **Recuperar operação interrompida**.

Notas detalhadas: [Português-BR](https://github.com/GxBrasilNOficial/Genexus-Open-API-Builder/blob/v0.1.0-alpha.8/Docs/Releases/0.1.0-alpha.8.md).

# English

This release introduces the durable operation journal (`GxOpenApiBuilder_OperationJournal`) and **Recover interrupted operation**: Apply, Sync, and Remove record intent before mutating the KB; an interrupted envelope blocks the next operation until recovery. It also closes the `B082` residual. Automatic continuation of an interrupted Apply/Sync **does not** exist in this Alpha.

## Choose the correct DLL

| File | Intended for |
| --- | --- |
| `GenexusOpenApiBuilder.Extension.dll` | GeneXus 18 Upgrade 14, U15, and later (**U14+**). Do not use with **U13−**. |
| `GenexusOpenApiBuilder.Extension-gx18u13.dll` | GeneXus 18 Upgrade 13 and earlier (**U13−**). Do not use with **U14+**. Formal validation on U13. |

The `-gx18u13` suffix only distinguishes the download. Do not rename the DLL or install both DLLs in the same IDE.

## Installation

In the GeneXus IDE, open **Extensions > Manage Extensions**, use **Add > Local**, and select the DLL that matches your version. Close the IDE completely and run `genexus /install` according to the installation documentation. Confirm the **Recover interrupted operation** menu item.

Detailed notes: [English](https://github.com/GxBrasilNOficial/Genexus-Open-API-Builder/blob/v0.1.0-alpha.8/Docs/Releases/0.1.0-alpha.8.en.md).
