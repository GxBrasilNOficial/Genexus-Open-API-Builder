# Release 0.1.0-alpha.8

**Data:** 2026-09-17

**Frente:** Sprint `S-B111` F3 — diário durável de operação, recuperação e residual `B082`

**Tag:** `v0.1.0-alpha.8`
**Release:** [Alpha no GitHub](https://github.com/GxBrasilNOficial/Genexus-Open-API-Builder/releases/tag/v0.1.0-alpha.8)

**Idiomas:** [Português do Brasil](0.1.0-alpha.8.md) · [Español](0.1.0-alpha.8.es.md) · [English](0.1.0-alpha.8.en.md)

Esta versão registra na Knowledge Base o que a extensão pretende fazer **antes** de mutar objetos, bloqueia Apply/Sync/Remover quando uma operação fica interrompida, e entrega o comando **Recuperar operação interrompida**. Fecha também o residual de desempenho/segurança do `B082`.

## O que muda para o usuário

- **Diário na KB:** Apply, Sync e Remover gravam o File `GxOpenApiBuilder_OperationJournal` (Root Module) antes de gravar ou apagar objetos de negócio.
- **Bloqueio seguro:** um envelope não terminal impede a operação seguinte; o motivo aparece no relatório.
- **Recuperar operação interrompida:** no menu principal e no contexto da Transaction — retomar remoção, fechar registro concluído ou **encerrar o registro** (sem apagar objetos) quando Apply/Sync pararam no meio.
- **Abortar honesto:** o quadro de progresso é modeless; Abortar conclui o objeto em curso e pode deixar a KB parcial — a saída é a recuperação, não “seguro antes de qualquer gravação”.
- **Remoção:** fila única por passadas; segunda remoção da mesma API deixa de parecer sucesso silencioso quando alvos já sumiram.
- **B082 residual:** índice coerente no Remover, guarda de operação única e endurecimentos de Preview/Folder.

**Limitação declarada:** continuação automática de Apply ou Sync interrompido **não** existe nesta Alpha.

O progresso visual (`0.1.0-alpha.7`), o `Delete` opt-in (`0.1.0-alpha.6`), os subníveis (`0.1.0-alpha.5`) e o contrato HTTP 422 (`0.1.0-alpha.4`) permanecem.

## Escolha obrigatória da DLL

Baixe e instale somente o arquivo correspondente à versão da sua IDE:

| Asset no GitHub Release | Serve para | Não serve para |
|---|---|---|
| `GenexusOpenApiBuilder.Extension.dll` | GeneXus 18 Upgrade 14, Upgrade 15 e posteriores U14+ | GeneXus 18 Upgrade 13 |
| `GenexusOpenApiBuilder.Extension-gx18u13.dll` | GeneXus 18 Upgrade 13 | GeneXus 18 U14+ |

O sufixo `-gx18u13` existe para distinguir o download público. Não renomeie uma DLL para fazê-la passar por outra linha e não instale as duas na mesma IDE.

## O que entra

- Schema V1 do diário, checkpoints confirmados, gate classificado e inventário/recibos por alvo.
- Comando `Recuperar operação interrompida` e preferência `ShowRecoveryOptionProactively` (ligada por padrão).
- Metadata de negócio `GOAB_API_METADATA_B060_V3` com `ownership.applicationId` (leitura tolerante a V1/V2).
- Recuperação de metadata órfã ao abrir o Wizard; quadro Diagnóstico e recuperação nas Preferências.
- Correções de localização do diário/recuperação e do catálogo de tradução (ordem por comprimento).
- Residual `B082` Etapas 1B/2/3 (índice no Remover, guarda, Folder tipado, DEMO alinhado).

## Validações

- Diário e recuperação exercidos na IDE (`wsEducacaoSpTeste`, `FabricaBrasil18Test`): Apply, Sync, aborto, bloqueio, retomada de remoção, legado e medição de custo (&lt;1% do tempo).
- Residual `B082` Etapa 1B aceito na IDE em `FabricaBrasil18Test` (2026-09-17).
- Compilações Release para as linhas U14+ (canônica) e U13 (satélite).

## Instalação

Siga o [guia público de instalação](../Public/INSTALL.md). Em resumo:

1. escolha a DLL pela tabela acima;
2. na IDE GeneXus aberta, use **Extensions Manager → Add > Local**;
3. feche completamente a IDE;
4. execute `genexus /install` na instalação correspondente;
5. reabra a IDE e confira os menus — inclusive **Recuperar operação interrompida**.

O `.nupkg` do GitHub Packages não é o instalador da IDE. Para a instalação pública, use o asset DLL do Release.

## Limitações conhecidas

- Continuação de Apply/Sync interrompido fora de escopo; use Recuperar para encerrar o registro e depois Wizard ou Remover.
- Preferências da KB ainda podem religar checkboxes de geração no reencontro (`B108`, estacionado; fora deste corte).
- Limitações de subníveis de `0.1.0-alpha.5` permanecem.
- O YAML OpenAPI nativo do GeneXus mantém as limitações documentadas em [B088](../Implementation/2026-08-10-B088-LIMITACOES-YAML-NATIVO.md).
- Em IIS + .NET Framework, os verbos `PUT` e `DELETE` exigem o ajuste do handler descrito no [README](../../README.md#requisito-de-ambiente-put-delete-e-patch-em-iis).
- A Alpha ainda não é a Beta.
