# GenexusOpenApiBuilder.Extension

Assembly da extensão **Genexus Open API Builder** publicado no GitHub Packages (feed NuGet).

## Isto não instala a extensão no GeneXus

O Extensions Manager **não** consome este pacote. Add > Local da IDE também **não** aceita `.nupkg`.

Para instalar na IDE GeneXus 18:

1. Baixe a DLL `GenexusOpenApiBuilder.Extension.dll` no [GitHub Release](https://github.com/GxBrasilNOficial/Genexus-Open-API-Builder/releases) da versão correspondente.
2. Siga o guia [Docs/Public/INSTALL.md](https://github.com/GxBrasilNOficial/Genexus-Open-API-Builder/blob/main/Docs/Public/INSTALL.md) (Add > Local → fechar a IDE → `genexus /install`).

## Para que serve este pacote

Artefato técnico com a mesma DLL em `lib/net471/`, útil para consumo via NuGet/`dotnet` ou inspeção do assembly — não substitui o Release como canal oficial de instalação.
